# Documentation

Use the following sources for the current product behavior:

- [`README.md`](../README.md) — installation, configuration, commands, and
  architecture overview.
- [`CHANGELOG.md`](../CHANGELOG.md) — shipped changes and breaking changes by
  release.
- [`moat/m3-memory-uplift-eval.md`](moat/m3-memory-uplift-eval.md) — the current
  operational procedure for the memory-grounding A/B evaluation.
- `kagura-engineer <command> --help` — the authoritative command-line options
  for the installed version.

The files under `plan/` and `superpowers/` are dated design and implementation
records. They are retained for decision history and may contain pre-implementation
status, internal plan numbers, or commands that were later changed or removed.
They must not be used as the current user guide or release-status tracker.
